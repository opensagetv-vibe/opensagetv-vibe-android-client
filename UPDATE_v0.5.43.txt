SageTV MiniClient Dev v0.5.43

Fix: standard test startup no longer uses one opaque dev_send_sequence call.

New path:
1. dev_open_search sends native SageTV Search.
2. Wait for hasTextInput=true and verified imeVisible=true.
3. dev_input_text_keyboard enters the required caller-supplied text through Android OS input.
4. dev_hide_ime hides the keyboard directly.
5. dev_wait_for_ime verifies imeVisible=false.
6. Direct SageTV UI commands start the selected recording.

Both mcp-media3-matrix and mcp-media3-comskip-matrix use this path.
IME state is now retained in compact status output.
This is host/MCP-only; no APK rebuild is required when v0.5.42 is already installed.
