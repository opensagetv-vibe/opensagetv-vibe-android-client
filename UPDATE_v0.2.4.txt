SageTV MiniClient Dev v0.2.4 test-runner patch

Fixes the MCP unit-test invocation used by ./dev.sh test.

Problem:
  PYTHONPATH=mcp/src python3 -m unittest mcp/tests/test_adb.py

Python 3.10 interpreted that path as module mcp.tests and failed with:
  ModuleNotFoundError: No module named 'mcp.tests'

Fix:
  PYTHONPATH=mcp/src python3 -m unittest discover -s mcp/tests -p 'test_*.py'

Install:
1. Extract this ZIP over the existing SageTV-MiniClient-Dev project root.
2. Overwrite files when prompted.
3. Run:
     ./dev.sh test
     ./dev.sh validate

Docker image rebuild is NOT required.
