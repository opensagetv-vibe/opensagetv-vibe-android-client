SageTV MiniClient Dev v0.5.5 — Phase A Seek / Timeline Cleanup

Changed:
- ExoPlayer Legacy exact 0 ms seeks are no longer discarded.
- Media3 exact 0 ms seeks are no longer discarded.
- Removed ExoPlayer Legacy and Media3 UI-thread seek polling/sleep loops.
- ExoPlayer Legacy and Media3 no longer mark a seek complete from arbitrary timeline changes.
- Confirmed seek discontinuity now updates the cached/media-session position from the backend-reported new position.
- IJK paused frame-step corrected from +1000 ms to approximately one 30 fps frame (+33 ms).
- Added Phase A regression tests and PHASE_A_SEEK_TEST.md.

Not changed:
- PUSH/PULL timeline rebasing.
- Shared seek coordinator / latest-command-wins behavior.
- Decoder selection or codec policy.
- GSY seek implementation.
