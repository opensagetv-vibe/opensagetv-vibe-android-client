SageTV MiniClient Dev v0.5.1 -> v0.5.2
========================================

Apply:
  Extract this update ZIP directly over the SageTV-MiniClient-Dev project root.
  Allow existing files to be overwritten.

Key changes:
  - Restores original SageTV IJK 0.8.8 Java/JNI runtime.
  - GSYVideoPlayer no longer inherits from IJKMediaPlayerImpl.
  - GSY no longer packages gsyvideoplayer-ex_so / GSY IJK native libraries.
  - GSY engine setting: Auto, Media3/ExoPlayer, Android System MediaPlayer, Legacy ExoPlayer.
  - Auto uses Android System MediaPlayer for SageTV PUSH/PULL custom data sources and Media3 for HTTP.
  - Adds Android MediaDataSource bridges for SageTV PUSH/PULL so GSY/System does not use ijkmediadatasource:.
  - AFTMM/mantis MPEG-2 MediaCodec workaround remains isolated inside legacy IJK.

Recommended verification after extraction:
  ./test_valitdate_build_install_lanuch.sh

Then select GSYVideoPlayer -> GSY Player Engine = Auto and retry the same recording.
