SageTV MiniClient Dev v0.3.3 telemetry normalization update

Why this update exists:
- v0.3.2 could leave a mixed telemetry source state because BaseMediaPlayerImpl.java was not included with the PlayerTelemetry constructor change.
- This patch re-ships the complete matched telemetry source/MCP/test set.

Install:
1. Stop any running ./dev.sh mcp process with Ctrl+C.
2. Extract this ZIP directly over the SageTV-MiniClient-Dev project root and overwrite files.
3. Run:
     ./dev.sh test
     ./dev.sh validate
     ./dev.sh build
     ./dev.sh install
     ./dev.sh launch
4. Confirm video starts before running telemetry tests.
5. While video is playing, from another terminal run:
     ./dev.sh mcp-telemetry

Docker image rebuild is NOT required.
