ANDROID SETTINGS MENU - EDITABLE DEFAULTS REVIEW

* marks the current code default, NOT the device's saved choice.
Move the * to the option you want, or edit a starred numeric value.
These proposed defaults are not applied merely by editing this file.
User-approved change: OpenGL UI and Unified HD Graphics default On. Upgrades
preserve explicitly saved values; absent settings use current defaults too.
Existing submenus retain their options; their internal defaults are not
changed by this menu reorganization.

All six top-level headings are light blue and collapsible.
Expansion: * Expanded initially; remembered independently after use.
Internal headings are labels, not additional pages.

SETTINGS-003 DEVELOPMENT
  Startup and long-press Fixed panels share the choices below. Existing saved
  values survive updates; only absent keys use defaults. Explicit unsupported
  combinations refuse with a reason. MIM currently requires MPEG-TS delivery;
  MKV/DVD MIM output and true per-client original-stock routing remain pending.
  Preserve existing legacy clients; do not globally redirect their launcher.

Applicability and navigation
  Gray out unavailable controls with an explanation; preserve saved values.
  No repeated "Next playback" labels in startup settings.
  Existing in-playback controls explain deferred changes when applicable.
  Long-press gear and Video/Audio/Captions shortcuts use the same definitions.
  Runtime defaults to this session; saving device defaults is explicit.
  Fixed processing/limits changed there are confirmed Next playback defaults;
  the separate Current-session Bitrate action never saves the device limit.
  Restore Saved Playback Defaults clears session overrides, not saved settings.
  Summaries distinguish configured choices from actual active transport.
  No active session: "Not connected" or "Connected - no active playback".
  Center/Enter/tap toggles a heading; focus remains on that heading.
  Return from a submenu restores the previous selection.
