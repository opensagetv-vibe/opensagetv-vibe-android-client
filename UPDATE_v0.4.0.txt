SageTV MiniClient Dev v0.4.0 update
==================================

Purpose
-------
- Preserve the confirmed v0.3.8 playback-working legacy ExoPlayer/IJK runtime.
- Add a third selectable backend using AndroidX Media3 ExoPlayer 1.11.0.
- Centralize player backend selection and remove IJK's dependency on legacy Exo utilities.
- Modernize the Dev Android build toolchain while retaining the old toolchain for source/existing.

Important
---------
The default remains "ExoPlayer Legacy (working baseline)".
Do not switch to Media3 until the default legacy Exo backend is confirmed working after this update.
Internal player telemetry remains disabled because it was proven to interfere with playback startup on the test Fire TV.

First build after extracting this update
----------------------------------------
./dev.sh image
./dev.sh test
./dev.sh validate
./dev.sh build
./dev.sh install
./dev.sh launch

Test order
----------
1. Confirm the default legacy ExoPlayer backend still starts and plays video.
2. In Settings, change the player to "Media3 ExoPlayer (Google current)".
3. Play the same recording/stream and report the result.
4. Test "IJKPlayer Legacy" separately as a fallback.

Build notes
-----------
- Dev: JDK 17, Gradle 8.13, AGP 8.13.2, compileSdk 36, Build Tools 36.0.0, minSdk 23.
- Existing untouched source: bundled JDK 8, Android platform 29, Build Tools 29.0.2.
- Fire TV SDK 25 remains above the Dev minSdk 23 requirement.
- Media3 initially uses platform MediaCodec only; the old Exo 2.18 FFmpeg extension is NOT reused by Media3.
- Legacy Exo remains at 2.18.1 with the existing custom FFmpeg 2.18.0 extension for baseline safety.
- IJK remains the local 0.8.8-SNAPSHOT legacy fallback.

If the Android build fails, capture the first compiler/dependency error rather than changing versions blindly.
