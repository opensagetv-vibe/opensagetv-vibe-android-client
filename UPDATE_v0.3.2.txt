SageTV MiniClient Dev v0.3.1 -> v0.3.2

Fix: telemetry app-private file I/O is now asynchronous on a dedicated background writer thread. This addresses the Fire TV playback-start regression observed after v0.3.1.

Apply:
1. Extract this ZIP over the SageTV-MiniClient-Dev project root and overwrite files.
2. Run: ./dev.sh test
3. Run: ./dev.sh validate
4. Run: ./dev.sh build
5. Run: ./dev.sh install
6. Run: ./dev.sh launch
7. Start video playback.
8. From another shell run: ./dev.sh mcp-telemetry

Docker image rebuild is NOT required. The Dev APK must be rebuilt/reinstalled because Android Java source changed.
