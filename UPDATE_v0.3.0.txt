SageTV MiniClient Dev v0.3.0 - Player Telemetry Update
======================================================

Applies over the current v0.2.10 project.

This update adds read-only local player telemetry and two MCP telemetry tools.
It does NOT change seek targets, buffering logic, decoder selection, retry logic,
or other playback behavior.

No Docker image rebuild is required.
The Dev APK MUST be rebuilt/reinstalled because Android Java source changed.

After extracting this ZIP over the project root:

  ./dev.sh test
  ./dev.sh validate
  ./dev.sh build
  ./dev.sh install
  ./dev.sh launch

Start video playback in SageTV MiniClient Dev, then in another shell run:

  ./dev.sh mcp-telemetry

Expected MCP tools now include:
  get_player_telemetry
  wait_for_player_event

Useful telemetry events include:
  LOAD_REQUEST
  FIRST_VIDEO_FRAME
  SEEK_REQUEST
  SEEK_COMPLETE
  FIRST_VIDEO_FRAME_AFTER_SEEK
  SNAPSHOT
  PLAYER_ERROR

See PLAYER_TELEMETRY.md for details.
