SageTV MiniClient Dev v0.5.62

Host/MCP-only matrix recovery update.

Changes:
- All matrix media actions now issue a short command and poll dev_player_state through the persistent ADB session.
- PASS is based on expected video/audio output counters advancing again.
- Target/landing position and wrapper state are diagnostic only.
- One dynamic WAIT line is rewritten in place and reports the current waitingFor condition.
- Detailed final CLI output includes counter deltas, wrapper diagnostics, decoder information, and Pull I/O deltas.

No APK rebuild is required. Existing debugStatusVersion 8 APK is sufficient.
