SageTV MiniClient Dev v0.4.9 update

Purpose:
- Retry IJK MPEG-2 hardware decoding on Fire TV using a compatibility-oriented MediaCodec startup path.

Key changes:
- IJK MPEG-2 MediaCodec default ON.
- MediaCodec sync mode ON.
- 2 MiB probe + 3 second analyze budget before hardware startup.
- Avoid fflags=nobuffer in hardware MPEG-2 mode.
- Prefer OMX.MTK.VIDEO.DECODER.MPEG2 on Amazon mantis.
- Known software codecs excluded from hardware selection unless explicitly allowed.
- Existing setting can disable MPEG-2 hardware and return to FFmpeg software decode.
- ExoPlayer and Media3 are untouched.
