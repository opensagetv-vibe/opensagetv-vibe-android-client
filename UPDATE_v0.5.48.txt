SageTV MiniClient Dev v0.5.48

Startup navigation fix:
- Before: ff -> right -> play_pause -> down -> play_pause
- Now:    ff -> right -> play_pause -> down -> select

Reason:
- The first play_pause opens the recording resume/start-choice flow.
- DOWN highlights Start From Beginning.
- A second play_pause resumes playback instead of confirming the highlighted option on this SageTV UI.
- Native SageTV SELECT (event 20 / Enter) now confirms Start From Beginning.

No Android source changed. APK rebuild/install is not required.
