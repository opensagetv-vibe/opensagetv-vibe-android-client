SageTV MiniClient Dev v0.2.4 -> v0.2.5

Fix: Android debug build failed at :android-tv:validateSigningDebug because
/root/.android/debug.keystore did not exist.

Apply:
  Extract this ZIP over the existing SageTV-MiniClient-Dev project and overwrite files.

No Docker image rebuild is required. The existing JDK image already contains keytool.

Then run:
  ./dev.sh test
  ./dev.sh ensure-debug-keystore
  ./dev.sh build

The generated signing file persists at:
  host project: ./adb/debug.keystore
  container:    /root/.android/debug.keystore

The first Fire TV install of the Dev app may require normal ADB authorization, but future Dev APK upgrades will retain the same debug signing identity as long as ./adb/debug.keystore is preserved.
