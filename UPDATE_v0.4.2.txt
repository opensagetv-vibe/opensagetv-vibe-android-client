SageTV MiniClient Dev v0.4.1 -> v0.4.2

Purpose:
- Repair AGP 8 / Gradle 8 android-shared compile-classpath/resource compatibility.

Changes:
- Explicit android-shared dependency: org.slf4j:slf4j-api:1.7.6
- Explicit android-shared dependency: androidx.appcompat:appcompat:1.3.1
- AutoConnectDialog uses public androidx.appcompat.R.style.Theme_AppCompat_Dialog
- Regression tests and validate_project.py guard these assumptions.
- No legacy player runtime behavior changes.

Apply by extracting this ZIP directly over the SageTV-MiniClient-Dev project root.

Then run:
  ./dev.sh test
  ./dev.sh validate
  ./dev.sh build

The Docker image does not need another rebuild if the v0.4.x image was already rebuilt successfully.
